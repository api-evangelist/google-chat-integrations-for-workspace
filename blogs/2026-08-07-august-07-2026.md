Feature Generally Available: You can now format Google Chat messages using standard Markdown syntax. By specifying the markupSyntax field as MARKUP_SYNTAX_MARKDOWN when creating a message using the Chat API, the body text is parsed using standard Markdown formatting. For more information, see Format your messages .
