Feature Developer Preview: The Google Chat Model Context Protocol (MCP) server now supports three new tools: mark_as_read , mark_as_unread , and list_memberships . These tools enable AI agents to update the read state of a space or thread and list memberships on the user's behalf. This feature is available as part of the Developer Preview Program .
