Feature Developer Preview: You can now call the Chat API to create and manage custom sections and organize conversations in a personalized view: Create section (RPC, REST) Delete section (RPC, REST) List sections (RPC, REST) Update section (RPC, REST) Position section (RPC, REST) List section items (RPC, REST) Move section items (RPC, REST) To learn more, see Section (RPC, REST) and SectionItem (RPC, REST) in the Chat API documentation.
