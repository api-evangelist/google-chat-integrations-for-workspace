Feature Generally Available: You can now configure who can view the list of members in a Google Chat space using the accessSettings.accessPermissionSettings.viewSpaceMembershipSetting field and the permissionSettings.viewSpaceMembership field on the Space resource in the Google Chat API. These fields let you define which target audiences in Google Workspace and which space roles can see the member list of a space. Requests that modify who can view space membership must include both fields in the updateMask and request body.
