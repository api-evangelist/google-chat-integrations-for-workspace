Feature Generally Available : Subscriptions to user read state updates in Google Chat are now generally available. You can use the Google Workspace Events API to subscribe to user read state updates in Google Chat. The following event types are supported: google.workspace.chat.spaceReadState.v1.updated : A user's space read state is updated.
