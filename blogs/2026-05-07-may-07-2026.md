Feature Chat MCP Developer Preview: Available as part of the Developer Preview Program, which grants early access to certain features. The Google Chat Model Context Protocol (MCP) server now supports two new tools: search_messages and send_message. These tools allow AI agents to search for messages across conversations and send messages behalf of the user. To get started with the new tools, see the Set up the Chat MCP server guide or view the full list of tools in the Chat MCP tool reference.
